# Changelog

## [0.1.0] - 2026-11-13

- Initial Derpibooru-focused reverse proxy release.
- Fixed upstream default: `https://derpibooru.org`.
- Added a runnable configuration-driven HTTP server entry point.
- Added exact-version Anubis 1.27.0 and 1.28.2 bridge adapters.
- Added session-isolated cookies, fixed-origin redirect mapping, streaming, Range, and WebSocket handling.
